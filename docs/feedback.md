# Public Feedback & Issues

We built DevFoundry to solve real-world development problems, and we want to know what works and what doesn't. 

If you are using DevFoundry, please share your thoughts!

## Quick Feedback Prompts
- **What did DevFoundry get wrong?** (e.g. false positives, incorrect remediation steps)
- **What did DevFoundry miss?** (e.g. undetected secrets, unflagged vulnerabilities)
- **What was confusing?** (e.g. command usage, output formats, CI policies)
- **What saved you time?** (e.g. baseline comparisons, remediation advice)
- **What would make you install it again?** (e.g. VS Code plugin, oundry init configuration wizard)

## How to Share Feedback
- **Open an Issue**: Use our Bug Report or Feature Request templates in the issue tracker.
- **Start a Discussion**: Go to GitHub Discussions to ask questions, share how you use DevFoundry in your CI, or suggest ideas.
