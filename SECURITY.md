# Security Policy

## Supported Versions

We actively support and apply security patches to the following versions of DevFoundry:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability in DevFoundry (e.g. credential leakage or scanning issues), please report it directly through GitHub Security Advisories or by emailing the project maintainers.

Please do not open public issues for security vulnerabilities until they have been reviewed and resolved.
